# 代表性代码文件抽取

从代码仓库中选择少量具有代表性的文件，并复制到一个独立目录中。

## 工作流程

### 1. 了解仓库

读取适用的仓库规则，并查看目录结构、README、项目配置和主要源码，了解项目的用途与代码组织方式。

### 2. 选择文件

根据项目实际情况自由选择文件，不要预设前端、后端、数据库或其他固定分类。

用户指定数量时按照用户要求选择；没有指定时通常选择 2 至 3 个。选择时关注：

- 能够体现项目的代码风格和实现质量。
- 包含有意义的逻辑，而不是只有声明或简单配置。
- 不需要读取大量关联文件也能理解主要意图。
- 优先选择项目自行编写的源码，不选择生成代码、第三方代码、配置或数据文件。

### 3. 创建样例目录

使用用户指定的目录；没有指定时使用 `code-sample/`。

将选中的文件复制到该目录，不修改原始文件。目录中同时创建一个简短的 `README.md`，用一句话说明这是从项目中抽取的代表性代码文件。README 中的文件数量应当与实际数量一致。

不要规定样例文件名、文件类型或固定目录结构；它们应当由当前项目和所选文件决定。

### 4. 简单检查

确认目录中包含 README 和正确数量的代码文件，文件内容完整，并且没有误带明显的密钥、账号或真实数据。

### 5. 完成

向用户说明样例目录位置和选中的文件。只有用户明确要求或仓库规则要求时才提交 Git。
